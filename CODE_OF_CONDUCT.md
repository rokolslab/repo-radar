# Code of Conduct

Repo Radar открыт для предложений, исправлений и дополнений. Участники обсуждений и pull requests должны придерживаться профессионального и предметного общения.

## Ожидаемое поведение

- Обсуждайте идеи, факты и технические решения, а не личности участников.
- Формулируйте замечания конкретно и проверяемо.
- Уважайте право авторов upstream-проектов на собственные технические и продуктовые решения.
- Не используйте issues и pull requests для спама, рекламы или продвижения проекта без содержательного обоснования его полезности для каталога.
- Не публикуйте персональные данные, секреты, токены, приватные адреса или иную чувствительную информацию.
- При обсуждении security-проблем следуйте `SECURITY.md` и не раскрывайте опасные детали без необходимости.

## Недопустимое поведение

Оскорбления, травля, угрозы, дискриминационные высказывания, намеренное создание конфликтов, публикация чужих персональных данных и другой явно деструктивный контент могут быть удалены, а участие пользователя — ограничено.

## Scope

Эти правила применяются к issues, pull requests, review-комментариям и другим публичным взаимодействиям внутри `rokolslab/repo-radar`.

Вопросы по модерации решает владелец репозитория.
