## Кратко

`agent-vmesto-chata` — русскоязычный практический курс по переходу от обычного общения с ИИ в формате чата к работе с coding agents. Особенность проекта в том, что курс ведет сам агент: пользователь открывает папку в Codex или Claude Code и пишет `начни курс`, после чего агент читает сценарий тьютора и последовательно ведет занятия.

Курс построен не вокруг абстрактных учебных упражнений, а вокруг реальной задачи пользователя. Уже с первых уроков агент создает рабочие артефакты, а прогресс, правила и накопленные знания сохраняются в файлах проекта.

## Какую проблему решает

При переходе от ChatGPT-подобного интерфейса к Codex/Claude Code основная сложность — не установка CLI, а изменение модели работы:

```text
чат
 │
 │ вопрос → ответ
 ▼
agent workspace
 │
 ├── файлы
 ├── инструкции
 ├── постоянный контекст
 ├── навыки
 ├── подагенты
 └── реальные действия
```

Репозиторий пытается обучить этому через практику внутри самой агентной среды.

## Как устроен курс

В корне лежат одинаковые `AGENTS.md` и `CLAUDE.md`. Они сообщают Codex/Claude Code, что текущая папка является учебным курсом, и направляют агента к `курс/тьютор.md`.

Основная структура:

```text
agent-vmesto-chata/
├── AGENTS.md
├── CLAUDE.md
├── README.md
└── курс/
    ├── тьютор.md
    ├── уроки/
    │   ├── урок-00.md
    │   ├── урок-01.md
    │   ├── ...
    │   └── урок-11.md
    └── материалы/
```

`тьютор.md` задает агенту правила преподавания: читать урок полностью, идти по сценарию такт за тактом, не выполнять лишние действия, сохранять прогресс, честно сообщать об ограничениях конкретного agent CLI и не редактировать исходные материалы пользователя без разрешения.

## Механика прогресса

Курс сохраняет состояние в рабочей папке. В частности, тьютор использует `мастерская/прогресс.md`, чтобы после перерыва понять, какой урок был завершен и что делать дальше.

Также курс постепенно вводит более долгоживущие элементы агентной среды:

- инструкции в `AGENTS.md` / `CLAUDE.md`;
- пользовательские правила;
- тематические файлы знаний;
- примеры;
- skills;
- ограничения `Нельзя никогда`;
- отдельные/параллельные агентные сессии там, где это поддерживает продукт.

## Требования

Нужен один из поддерживаемых coding agents:

- Codex;
- Claude Code.

Отдельный backend или API не требуется: содержимое курса — Markdown-файлы и инструкции агенту.

## Как можно использовать

### 1. Пройти курс целиком

Самый прямой вариант — скачать репозиторий в отдельную папку, открыть ее в Codex или Claude Code и пройти занятия на реальной задаче.

### 2. Изучить методику проектирования agent-native обучения

Проект интересен как пример необычной архитектуры учебного продукта:

```text
Markdown curriculum
       │
       ▼
AGENTS.md / CLAUDE.md
       │
       ▼
Codex / Claude Code
       │
       ▼
agent-tutor
       │
       ▼
реальные артефакты + сохраненный прогресс
```

То есть сам coding agent одновременно является runtime курса и преподавателем.

### 3. Использовать как образец для собственных внутренних курсов

Подход можно адаптировать для обучения сотрудников работе с конкретным инструментом, внутренним процессом или репозиторием: сценарии уроков хранятся рядом с рабочими материалами, а агент ведет пользователя и проверяет результат.

### 4. Сравнить Codex и Claude Code

Поскольку курс специально учитывает различия возможностей продуктов, его можно пройти или частично проверить в обоих окружениях и увидеть различия в skills, subagents, persistent instructions и работе с файлами.

## Сильные стороны

1. Agent-native формат: курс невозможно полностью свести к просмотру видео или чтению текста.
2. Работа на настоящей задаче пользователя вместо искусственных упражнений.
3. Состояние курса хранится в файлах и переживает перерыв между сессиями.
4. Поддерживается и Codex, и Claude Code через параллельные `AGENTS.md`/`CLAUDE.md`.
5. В тьюторе явно прописаны правила честности, контроля изменений и работы с пользовательскими файлами.
6. Хороший reference для проектирования собственных agent-guided workflows.

## Ограничения и риски

1. Репозиторий крайне молодой: создан 18 августа 2026 года.
2. На момент добавления всего несколько stars и нет forks, поэтому независимой проверки почти нет.
3. Лицензия в GitHub metadata не указана; использовать содержимое как основу собственного распространяемого курса без выяснения условий не следует.
4. Качество обучения сильно зависит от того, насколько точно конкретная версия Codex/Claude Code следует инструкциям курса.
5. Некоторые механики могут отличаться или перестать работать при изменениях agent CLI.
6. Это учебный продукт, а не универсальная система управления агентами.

## Пересечения с другими проектами Repo Radar

### mattpocock/skills

`agent-vmesto-chata` учит самой модели работы с агентом; `mattpocock/skills` дает более продвинутые инженерные процессы. Логичная последовательность — сначала базовый agent workflow, затем specialized skills.

### nativeprompt

После освоения работы с агентами `nativeprompt` можно использовать как следующий уровень — анализировать, как постановка задачи должна меняться между разными model families.

### nodeterm

Курс объясняет базовую агентную работу, а Nodeterm решает уже операционную проблему множества параллельных agent sessions.

1. Клонировать курс в отдельную учебную папку.
2. Открыть ее в Codex.
3. Выбрать реальную, но некритичную задачу.
4. Пройти несколько первых уроков и проверить, насколько корректно создается `мастерская` и сохраняется прогресс.
5. Отдельно оценить полезность подхода как шаблона для собственного agent-guided обучения.
