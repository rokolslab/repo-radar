# Security Policy

Repo Radar — документационный каталог и не распространяет исполняемый код рассматриваемых проектов.

## Уязвимости во внешних проектах

Если проблема безопасности относится к репозиторию, который рассматривается в Repo Radar, сообщайте о ней владельцам соответствующего upstream-проекта через их официальный security process, Security Advisories или другой указанный ими канал.

Не публикуйте в Repo Radar эксплуатационные детали неизвестной уязвимости только ради дополнения карточки.

## Проблемы в Repo Radar

Если обнаружены:

- вредоносная или подменённая ссылка;
- ошибочная security-рекомендация;
- случайно опубликованный секрет, токен или чувствительные данные;
- инструкция, которая создаёт существенный риск при буквальном выполнении;

создайте issue с минимально необходимым объёмом информации. Если публикация деталей сама по себе создаст риск, используйте приватный канал связи владельца репозитория вместо публичного issue.

## Безопасное использование материалов

Наличие проекта в Repo Radar не является гарантией его безопасности. Перед запуском внешних installer-скриптов, контейнеров, бинарных файлов или конфигураций необходимо:

1. проверить upstream-репозиторий и источник артефакта;
2. прочитать исполняемый скрипт или release notes;
3. проверить запрашиваемые права и сетевые порты;
4. не передавать реальные production-секреты в тестовую среду;
5. по возможности проводить первый запуск в изолированном стенде.
